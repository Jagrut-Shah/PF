# ÉLAVA Perfumes — Stage 0 Project Foundation

Frontend architecture and foundation for the ÉLAVA premium perfume web application.

## Tech Stack
- **React** (v19)
- **Vite** (v8)
- **React Router** (v7)
- **Tailwind CSS** (v4)
- **Lucide React**

## Scripts
- `npm run dev` — Launch development server
- `npm run build` — Build production bundle
- `npm run preview` — Preview production build locally
